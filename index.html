Fullstack Solo Project

Trello — Real-Time Kanban Workspace

A decoupled full-stack MERN task & project management platform featuring drag-and-drop boards, Socket.IO real-time team collaboration, Dual-Auth security, and automated CI testing.

Live Demo Frontend Repo Backend Repo
trello-web-tawny.vercel.app/boards/board-03
Interactive Kanban Board with @dnd-kit drag-and-drop, live user presence indicator, custom Unsplash backgrounds, and Light/Dark mode.
Frontend Architecture (React + Vite)
  • Smooth column & card drag-and-drop powered by @dnd-kit with custom collision detection and optimistic updates
  • Predictable state persistence via Redux Toolkit & Redux Persist plus Axios interceptors for silent token refresh
  • SEO-friendly board slugs (/boards/:id/:slug) and card modal deep-linking (?cardId=...)
  • Rich Markdown descriptions, progress checklists, card filtering, Light/Dark themes, and Unsplash backgrounds
Backend & Real-Time Engine (Node.js + MongoDB)
  • Dual-Auth Security supporting both HttpOnly Cookies and Bearer headers + JWT Refresh Token Rotation + Google OAuth 2.0
  • Socket.IO board room synchronization (board:<id>) for live presence, instant card updates, comments & invitations
  • MongoDB Aggregation Pipelines unifying board invitations and approaching/overdue card deadline alerts
  • Cloudinary file/cover uploads, Brevo verification emails, Swagger docs (/v1/docs), Unit/E2E tests & GitHub Actions CI
